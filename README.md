# Calculator App 

A simple and beginner-friendly Calculator App built using HTML, CSS, and Vanilla JavaScript. I made this as a part of my web development learning journey to practice frontend basics.

##  Features
- Clean and modern user interface designed with CSS Grid.
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division).
- Clear screen button (C) to reset calculations.
- Responsive display screen (readonly to prevent manual keyboard typing errors).

##  Tech Stack
- **HTML5** - For structure
- **CSS3** - For styling and layout (Grid)
- **Vanilla JavaScript** - For calculator logic and calculations

##  What I Learned
Through this project, I got more comfortable with:
- JavaScript DOM manipulation and functions.
- Using `eval()` for simple math calculations.
- Organizing file structures for a frontend project.

## 🔗 Live Demo / Usage
You can clone this repository and open `index.html` in any web browser to test the calculator!
